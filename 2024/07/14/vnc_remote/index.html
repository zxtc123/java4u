vnc远程连接设计

需求背景

需要在云端（浏览器）来远程使用远端的虚拟机，通过帐号的切换达到多个用户共享一台或多台虚拟机，从而实现对稀缺资源（如带GPU虚拟机）的复用。

flowchart LR
    A[vnc viewer]-- access via novnc on browser ---B[vnc service]

技术选型

vnc viewer: novnc the open source VNC client
vnc service: x11vnc a VNC server for real X displays
agent: 任意web框架即可

相关资料

  1. x11vnc启动后提供的服务类型是WebSocket,不是普通的HTTP服务。x11vnc使用RFB(Remote Framebuffer)协议进行VNC控制,而RFB协议本身就是建立在WebSocket协议之上的。这需要流量转发的过程中有中间件支持websocket的转发或者http对websocket的转换。

方案设计

  1. 每台机器同一时间只允许一个用户使用，也就只允许一个用户获取到机器的远程连接（可以考虑加锁的方法防止并发调用导致的异常）
  2. 一台机器需要提供给多个用户使用而不会相互影响，考虑使用用户系统（当前方案目前只考虑linux系统），通过linux上用户的隔离达到多个用户使用隔离不相互影响的效果。
  3. 在每个用户自己的空间下启动vnc service，这样浏览器远程连接后，显示的就是当前用户的桌面和系统。
  4. VNC支持口令登录，每次创建连接时动态生成密码，在使用密码启动vnc service，将口令返回给console，console使用密码进行登录
  5. 当前方案考虑到降低对远程机器的侵入，使用ssh远程连接机器进行相关操作

流程图：

sequenceDiagram
  participant console
  participant agent
  participant remote mechine
  console->>agent: apply a remote connection
  activate agent
  agent-->agent: generate vnc passwd
  agent->>remote mechine: start vnc service
  remote mechine-->>agent: start complete
  agent-->> console: return vnc passwd
  deactivate agent
  console-xagent: too many request

安全加固

系统加固

  1. linux的文件系统可以保证多个用户的文件相互隔离，可以防止其他用户的隐私文件泄漏或被修改。但无法保证系统进程中相关信息不会被其他用户获取（禁止进程信息被非当前用户获取？使用同一台机器的用户需要满足在同一个信任域内？）

证书

为满足安全，考虑vnc启动wss服务。查询x11vnc官网，x11vnc支持-ssl参数启动wss。
https://github.com/LibVNC/x11vnc/blob/master/doc/SSL.md
当前支持自签证书和使用已经存在的证书启动并且也支持生成CA来自签证书。可以考虑自身业务场景和安全要求进行选择。如果对安全没有太多要求也可以使用vnc自带的功能-ssl TMP和-ssl ATON,不生成证书或生成临时证书启动。
当然也可以随时生成自签证书给vnc使用，查看x11vnc源码：https://github.com/LibVNC/x11vnc/blob/master/src/ssltools.h 可以发现x11vnc底层就是直接调用openssl来生成证书的，在特定环境下可以直接调用openssl来生成xnc需要的证书。

# 当前方案可以使用openssl给指定用户目录生成证书
openssl req -newkey rsa:2048 -keyout /home/user/.vnc/certs/key.pem -nodes -x509 -days 365 -out /home/user/.vnc/certs/cert.pem -batch
# vnc指定的证书需要同时包含证书和私钥
cat /home/user/.vnc/certs/key.pem /home/user/.vnc/certs/cert.pem > /home/user/.vnc/certs/service.pem
# vnc启动时指定该证书，安全考虑也可以对证书进行加密，vnc自身也支持对证书加密
x11vnc -ssl /home/user/.vnc/certs/service.pem
